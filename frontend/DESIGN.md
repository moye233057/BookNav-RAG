# DESIGN.md

问答页视觉与基础交互。一页一对一对话，不是设计系统。实现手法见页面代码；本文件管配色、间距、区域。

## 配色

| Token | 值 | 用在 |
|-------|-----|------|
| 页底 | `#f3f4f6` | `body` |
| 主底 | `#ffffff` | 对话栏、侧栏 |
| 正文 | `#1a1a1a` | 标题、答案 |
| 次文 | `#6b7280` | 说明、空状态、原文片段 |
| 线 | `#e5e7eb` | 顶栏、侧栏、输入框分割 |
| 用户泡 | `#e8f1ff` | 用户消息 |
| 助手泡 | `#f8fafc` | 助手消息 |
| 错误泡 | `#fef2f2` / `#991b1b` | 失败 |
| 主按钮 | `#1d4ed8` / `#ffffff` | 提问、当前选中的参考资料 |
| 标签芯片 | `#eef2ff` / `#1d4ed8` | 意图识别这一层给出的过滤标签 |

## 间距

顶栏与侧栏标题：`16px 20px`。对话区与侧栏正文：`16px 20px`。气泡间距 `14px`，内边距 `12px 14px`，圆角 `10px`。输入区内边距 `12px 20px 16px`。控件间隙 `8px`。

## 布局

整页不滚动。宽屏两列：左对话（顶栏下消息 + 底输入），右参考资料。对话区一根滚动条在消息列表；侧栏一根滚动条在引用列表。输入区和顶栏不滚。

窄屏（小于 `900px`）改成上下堆：对话区高度 `72vh`，侧栏高度 `40vh`，各自内部滚动。

## 交互

- 页加载生成一次 `session`，每问都带；刷新才换会话。
- Enter 提问，Shift+Enter 换行。提问中禁用输入与按钮。
- 不手填来源与过滤标签。意图识别这一层给出的过滤标签直接显示为芯片，芯片跟着当前选中的那条助手消息走；没有则整行不渲染。芯片文案用 `field` 原词，不写死品牌/车型。
- 每条助手消息旁有「参考资料」按钮。点击后侧栏换成该次检索的引用。新答案默认选中自己。
- 侧栏标题写「参考资料」。没有则写「还没有参考资料」。
- 答案气泡不跟引用列表。不上传、不切库、不加第二页。
